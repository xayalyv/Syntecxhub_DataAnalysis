# Sales Performance Dashboard (SyntechX Hub Virtual Internship)

## Project Overview
This repository contains an interactive **Power BI Sales Performance Dashboard** developed during my virtual internship. The primary objective of this project was to transform raw sales data into actionable business insights by performing ETL processes, data modeling, DAX engineering, and designing an intuitive user interface following data visualization best practices.

---

## Key Performance Indicators (KPIs)
The dashboard highlights the following high-level business metrics:
* **Total Revenue:** \$107.32M
* **Total Profit:** \$23.97M
* **Average Satisfaction Score:** 2.96 / 5.00
* **Sales Channel Performance:** Retail operations lead profitability with **\$8.25M** in profit, closely followed by Online (**\$8.19M**) and Wholesale (**\$7.53M**).

---

## Key Analitical Insights

1. **Year-Over-Year Trend:** Customer transaction counts remained stable and strong through 2024 and 2025 (~365+ transactions). However, a significant downward trend is observed in 2026, dropping to nearly 270 transactions. This downturn serves as a critical warning signal for business health.
2. **Product Category Demand:** **Clothing** (109.2K units) and **Electronics** (103.2K units) are the volume drivers for the business. In contrast, **Furniture** marks the lowest sales volume with 94.4K units sold.
3. **Geographical Distribution:** Market penetration across regions is highly balanced. The **West** region accounts for the largest share of transactions (28% / 280 transactions), while the **South** region holds the smallest share (23% / 230 transactions).
4. **Salesperson Performance:** Revenue and profit margins are distributed evenly among the sales team (Alice, Eve, Bob, Charlie, and David). Each salesperson maintains a stable profit margin contribution of approximately 18% to 19%, reflecting highly consistent team performance.

## Tech Stack & Skills Demonstrated
* **Power Query:** Data cleaning, type transformation, and data profiling.
* **DAX (Data Analysis Expressions):** Formulating dynamic measures for core metrics (Total Revenue, Total Profit, and Customer Satisfaction).
* **Data Visualization & UI/UX:** Applied a clean, dark-blue corporate palette using a scannable Z-pattern layout (KPIs on the right, global trends on the left).
